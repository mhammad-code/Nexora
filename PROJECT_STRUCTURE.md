# Nexora - Project Structure

## Main Directories

- `app/` - Next.js application routes, pages, and layouts.
- `components/` - Reusable UI components.
- `features/` - Feature-specific application code.
- `lib/` - Shared utility functions and libraries.
- `hooks/` - Custom React hooks.
- `types/` - TypeScript types and interfaces.
- `config/` - Application configuration.
- `public/` - Static assets such as images and icons.

## Development Guidelines

- Keep reusable components inside `components/`.
- Keep feature-specific code inside `features/`.
- Keep shared utilities inside `lib/`.
- Use `types/` for shared TypeScript definitions.
- Keep application routes inside `app/`.
