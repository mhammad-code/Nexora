
# Nexora

Nexora is a project management application inspired by Jira and ClickUp.

## Project Overview

Nexora helps teams manage projects, organize tasks, track progress, and collaborate efficiently.

## Technology Stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Docker

## Development Setup

Install dependencies:

npm install

Start development server:

npm run dev

Open http://localhost:3000 in your browser.

## Git Workflow

- main: Stable branch.
- feature/*: New features and tasks.
- fix/*: Bug fixes.
- Changes should be reviewed through Pull Requests before merging.
